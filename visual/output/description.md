# Server host

The server-host component at version 0.13.0 provides com.clodhub/server-host version 1.0.0 to an illustrative application consumer, which in turn supplies com.clodhub/room-session version 1.0.0 and com.clodhub/room-directory version 1.0.0. The 3 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
